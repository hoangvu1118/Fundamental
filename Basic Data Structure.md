### Dynamic Arrays 
* Size can be changed 
```C++
// Add elements
vector<int> v; 
v.push_back(3); // [3] 
v.push_back(2); // [3,2]

// Access elements
cout << v[0] << "\n"; // 3 
cout << v[1] << "\n"; // 2

// Access size
v.size()
for (auto x : v) { // Shorter way to iterate through a vector
	cout << x << "\n"; 
}

// Acces
```
