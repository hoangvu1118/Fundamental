### WHAT IS IOT?
- Connecting physical world to the internet using sensor
- Devices:
	- Gather data using sensors
	- Interact using actuators
	- Connect with peer devices and the internet

CLOUD services
- Process sensor data
- dispatch - actuator requests

Edge processing
- Don't need connectivity
- process data locally --> using AI models trained in the cloud
